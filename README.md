# Основа веб-приложения на Laravel

Простой учебный проект по ТЗ на фреймворке Laravel (v1.0).

## Что сделано:
1. **Проект на Laravel** создан через Composer.
2. **Базовые настройки**:
   - Секретный ключ шифрования (`APP_KEY`) сгенерирован
   - Часовой пояс: `Europe/Moscow`
   - Локаль: `ru`
   - Режим отладки: `APP_DEBUG=true`
3. **Маршруты** (`routes/web.php`):
   - `GET /` — главная страница
   - `GET /form` — страница с формой
   - `POST /form` — отправка и обработка формы
   - `GET /data` — страница с таблицей данных
4. **Контроллер** (`app/Http/Controllers/MainController.php`) для обработки всех роутов.
5. **Представления (Blade)** в `resources/views/`:
   - Базовый лейаут: `layout.blade.php`
   - Вставка хедера с логотипом и меню: `header.blade.php`
   - Вставка футера: `footer.blade.php`
   - Расширения лейаута для страниц: `home.blade.php`, `form.blade.php`, `data.blade.php`
6. **Форма**:
   - Отправка методом `POST`
   - Серверная валидация полей (`name`, `email`, `message`) и вывод ошибок
   - Сохранение полученных данных в файл JSON с уникальным именем (`storage/app/data/data_*.json`)
   - Вывод сообщения об успехе
7. **Таблица**: вывод всех данных, полученных через форму, на отдельной странице `/data`.
8. **Git**: репозиторий с фиксацией версии тегом `v1.0`.

## Запуск:
```bash
php artisan serve
```
Сайт доступен по адресу: http://127.0.0.1:8000
